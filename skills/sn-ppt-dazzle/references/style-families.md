# 风格家族库（sn-ppt-dazzle）

选风格的顺序：**先按场景庄重度圈定候选域（见 SKILL.md §3），再在候选域内按题材气质点名一个 family**。同一主题往往有多个可行 family——避免惯性总选同一个；标 ★dazzle 的家族在自由档场景下优先考虑。palette 仅是示例方向，**每个 deck 都要为主题现场调一组精确 hex**，不要照抄。

通用禁忌（所有家族适用）：暖米黄/奶油/宣纸底（#FBF7F0 类 R>G>B 暖白）禁做主背景；做旧纸张纹理禁用；字体禁 Inter/Roboto/Arial/Open Sans/Lato/Space Grotesk 默认套路。

**禁用风格：瑞士极简 / 国际主义排版（swiss_typographic）——一律不用。** 即便是庄重/学术/研究类场景，也改用深色商务、编辑杂志、数据仪表盘等其他沉稳系家族，不要走"瑞士极简/网格排版"那一套。

---

## 沉稳系（庄重档场景的主力）

### editorial_magazine — 杂志编辑风
- **气质**：大标题 + 栏宽对比、首字下沉、图文混排、留白节奏，像高端杂志专题。
- **适用**：行业洞察、文化内容、品牌故事、年度回顾；**禁用**：强数据型监控汇报。
- **palette 示例**：墨黑 #141414 + 米白替代用冷白 #FAFAF8 + 酒红 #8E2433 ／ 深海军 #10243E + 鎏金 #C9A227。
- **字体方向**：display 衬线（Playfair 之外多换：Libre Caslon / Zilla Slab / Noto Serif SC），body 无衬线对比。
- **fancy 发力**：首字/标题的 mask reveal、图片异形裁切 + 视差、栏块 staggered 入场、阅读节奏感的过渡（横向位移 + 模糊溶解）。

### data_dashboard — 数据新闻 / 仪表盘
- **气质**：图表先行、数字精确、面板网格、冷静配色 + 功能性重音。
- **适用**：业务汇报、财报、运营复盘、科研数据；**禁用**：抒情文化叙事。
- **palette 示例**：深空蓝 #0D1B2A + 青 #4CC9F0 + 琥珀警示 #FFB703 ／ 碳黑 #101418 + 荧绿 #00E676 + 灰阶矩阵。
- **字体方向**：display 几何无衬线，数字必须等宽（JetBrains Mono / IBM Plex Mono）。
- **fancy 发力**：图表入场动画（柱状生长、折线 draw-in、环图扫描）、KPI count-up、面板描边/分隔线扫光、背景径向光晕微脉冲（**不要用方格网格底纹**）、数据点 hover 光晕。庄重档里最能"绚得其所"的家族——把数据演出来。

### luxury_minimal — 奢侈极简 / 高端留白
- **气质**：大留白、纤细衬线、金属/单色重音、缓慢优雅的动效节奏。
- **适用**：高端品牌、腕表珠宝、地产、艺术拍卖；**禁用**：儿童、活力营销、技术深度分享。
- **palette 示例**：曜石黑 #0B0B0D + 香槟金 #D4B886 ／ 深胡桃 #1C1714 + 象牙改用冷白 #F5F5F3 + 黄铜 #B08D57。
- **字体方向**：纤细衬线 display（Cormorant 之外：Marcellus / Italiana）+ 极简无衬线 body；中文配 Noto Serif SC Light。
- **fancy 发力**：缓慢的光泽扫过（gradient sweep）、克制的视差、金属质感渐变、字距缓张的入场。注意第 6 条反空壳：留白≠空白，hero 必须有完整信息层级。

### modern_flat_saas — 现代扁平 / 产品风
- **气质**：干净明亮、卡片圆角、清晰层级，当代产品语言。
- **适用**：产品介绍、功能发布、培训教程；**禁用**：文化艺术叙事（气质太"工具"）。
- **palette 示例**：冷白 #F7F9FB + 深靛 #2B3A67 + 珊瑚 #FF6B6B ／ 暗模式：#0F172A + 天青 #38BDF8 + 亮橙 #FB923C。
- **字体方向**：友好几何无衬线（Sora / Manrope / Figtree），避免 Inter。
- **fancy 发力**：卡片 stagger 浮入、功能示意的 micro-interaction 演示、渐变光晕背景呼吸（**非网格**）、hover 磁吸。

## 中性系（可素可炫，看题材）

### glass_neumorphic — 玻璃拟态
- **气质**：毛玻璃模糊、半透明层叠、柔和高光，轻盈通透。
- **适用**：科技产品、数据概览、概念展示；**禁用**：需要厚重权威感的政企场合。
- **palette 示例**：深紫蓝底 #1A1B3A + 玻璃面板 rgba 白 + 霓虹青/品红重音 ／ 冷白底 + 低饱和蓝灰玻璃。
- **fancy 发力**：backdrop-filter 层叠深度、光斑在玻璃后游动、卡片 3D 倾斜跟随鼠标。

### organic_handdrawn — 自然有机 / 手绘插画
- **气质**：手绘线条、不规则形、自然色、温暖人文（非做旧古籍）。
- **适用**：教育、儿童、公益、生活方式、食物；**禁用**：金融法务、硬科技。
- **palette 示例**：森绿 #2D5A3D + 暖橙 #E8842C + 奶白改冷白 ／ 靛蓝夜空 #1B2A4A + 萤黄 #F5D547。
- **字体方向**：手写体 display（中文 LXGW WenKai / ZCOOL 系）+ 圆润无衬线 body。
- **fancy 发力**：SVG 路径 draw-in（手绘笔触感）、元素轻微摇摆呼吸、纸片视差层（不做旧）。

### brutalist_web — 网页野兽派
- **气质**：裸露结构、粗边框、超大字、高对比的原始张力。底色必须冷/深/饱和，**绝不暖卡纸米白**。
- **适用**：设计活动、先锋品牌、开发者主题；**禁用**：一切庄重档场景。
- **palette 示例**：纯黑 + 荧光绿 #00FF66 + 纯白 ／ 克莱因蓝 #002FA7 + 黑 + 白。
- **fancy 发力**：巨字滚动/弹跳入场、marquee、边框闪烁、故意的"硬"过渡（瞬切 + 抖动帧）。

### vintage_manuscript — 复古手稿（受限：仅当 query 明确要求复古/古籍气质才可用）
- 做旧纸张/羊皮纸是被过度使用的 AI 套路，默认禁用。若 query 点名要，也要用配色与排印表达年代感，不要噪点纹理糊脸。

## ★dazzle 系（自由档场景优先考虑）

### cyberpunk_neon — 赛博朋克 / 霓虹科技 ★
- **气质**：暗底 + 霓虹重音、扫描线、HUD、发光描边，未来都市。
- **适用**：科技发布、游戏电竞、AI/数据主题的自由档分享；**禁用**：答辩、政企、医疗。
- **palette 示例**：纯黑 #0A0A0B + 信号绿 #00FF88 + 警示橙 #FF6B1A ／ 深紫夜 #120B1F + 品红 #FF2A6D + 电青 #05D9E8。
- **字体方向**：等宽 display（JetBrains Mono / Space Mono）+ 干净无衬线 body；中文可配得意黑。
- **fancy 发力**：终端 HUD 元素、glitch 文字、CRT 扫描线、canvas 粒子网络、霓虹辉光脉冲、数据流背景。

### immersive_3d — 沉浸式 3D / 景深体验 ★（空间型题材的强选项）
- **气质**：真 3D 场景、景深视差、镜头运动，空间即叙事。
- **适用（仅空间型题材）**：建筑/古迹园林、天体天文/太空、空间地形地貌（含山地、雨林等自然景观）；次级也可：分子晶体结构、实体产品三维。**禁用**：人文叙事 / 抽象概念 / 数据报告 / 教学等非空间题材（3D 沦为为炫而炫，用 2D/CSS 创意更贴题）、纯文字密集汇报、庄重档。
- **palette 示例**：随场景定，注意雾色与底色统一（scene.fog 配 --bg）。
- **fancy 发力**：**代码参数化搭建真 3D 场景**（BoxGeometry/Cone/Plane/Torus/Sphere 组合出建筑·地形·天体，≥10 实体 + 三类光）+ Three.js 全局场景贯穿全场、翻页驱动相机沿弧线巡游、粒子星场、深度视差。完整范例见 fancy-cookbook「代码搭建 3D 场景」+「单一 3D 世界相机航点运镜」。锁 r128（见 SKILL.md §8）。**只在上面的空间型题材用它**（非空间题材别硬套）；**选了就要真做出 3D，不许降级成 2D 假装沉浸**。

### maximalist_collage — 极繁 / 拼贴 ★
- **气质**：信息过载之美、图层叠加、撞色、贴纸感密集排版。
- **适用**：潮流文化、音乐节、创意征集；**禁用**：一切庄重档 + 数据密集内容。
- **palette 示例**：高饱和多色撞（品红/柠檬黄/电蓝/黑），用黑或白做地。
- **fancy 发力**：多层错位视差、元素散落入场再聚合、旋转贴纸、marquee 条。

### memphis_playful — 孟菲斯 / 后现代俏皮 ★
- **气质**：明快撞色、波点锯齿不规则几何、俏皮错位。
- **适用**：青少年教育、活动预告、轻松团建分享；**禁用**：庄重档。
- **palette 示例**：奶白改冷白底 + 品红 #F72585 + 钴蓝 #3A0CA3 + 柠檬 #FFD60A。
- **fancy 发力**：几何元素弹跳入场（spring 缓动）、图形随页滚动旋转、波点背景漂移。

### comic_pop — 漫画 / 波普 ★
- **气质**：网点、对话框、粗轮廓、波普撞色的叙事感。
- **适用**：故事化分享、产品趣味介绍、活动回顾；**禁用**：庄重档。
- **palette 示例**：报纸白 + 波普红 #ED1C24 + 黑描边 + 半调网点青。
- **fancy 发力**：分镜式翻页（格子推进）、拟声词爆炸入场、半调网点纹理、对话框弹出。

### retrofuturism_y2k — 复古未来 / Y2K ★
- **气质**：千禧金属质感、镭射渐变、星瀑/光速隧道纵深、芯片紫粉青。
- **适用**：音乐潮流、数码文化回顾、创意主题；**禁用**：庄重档。
- **palette 示例**：深紫 #1A0B2E + 镭射渐变（粉#FF71CE→青#01CDFE→紫#B967FF）+ 铬银。
- **fancy 发力**：铬金属字渐变扫光、镭射 holographic 质感（conic-gradient + blend）、星瀑 / 光速隧道纵深、扫描光带。**（禁透视网格地平线——网格底纹一律不用，用光速隧道/星瀑表达 Y2K 纵深。）**

### bauhaus_geometric — 包豪斯 / 构成主义（editorial 簇但可偏炫用）
- **气质**：红黄蓝原色 + 黑、圆方三角、对角动势。
- **适用**：设计教育、艺术展览、创意方法论；庄重档可用其克制版本。
- **palette 示例**：米白改冷白 #F2F2EE + 正红 #D90429 + 钴蓝 #1D3AA8 + 明黄 #FFC300 + 黑。
- **fancy 发力**：几何形状的构成式入场（旋转/平移对位）、对角线驱动的过渡、形状与文字的 mask 互动。
