# 设计风格库(风格 / 色调 / 主色)

规划阶段定“风格方向”时的**参考素材库（非必选）**。先看目录，只进入一个最相关的风格群组；若需要现成的系统关系，再补读一套“成套协调系统”。完成选择后立即停止，不为比较而扫完整库。

最终要在三个维度各定一个并贯彻全套，再据此写 `base.css` 的 token：

1. **设计风格**(74 种,13 群组)—— 整体视觉语言 / 版式气质;
2. **色调**(22 种,5 类)—— 独立于具体颜色的"调子"(明暗、冷暖、饱和、单双色、风格化命名);
3. **主色**(29 种)—— 核心强调色 + 品牌情绪锚点,带 hex 和情绪关键词。

选择原则:**让风格服务于 brief**(党政选党政风、儿童选幼教风、奢侈品选高端奢华……),不要无脑套同一种。挑定后把主色 hex、色调倾向落进 `base.css` 的 `--accent` / `--bg` / `--ink` 等 token。

> **最短阅读路径：**目录 → 一个风格群组 → 一个色调 → 一个主色；只有整册协调仍拿不准时才补读〈四、成套协调系统〉。协调系统只借关系和比例，不复制整套外观。排版、对比度和调色板硬规以 `design-rules.md` 为准，不在本文件重复。

## 目录

- 一、设计风格(74 种,13 群组):现代科技、极简商务、中式、日韩、欧美复古、艺术创意、生活治愈、自然生态、工业材质、杂志影像、行业垂直、特殊视角、二次元潮玩
- 二、色调(22 种,5 类):明度 / 对比、冷暖 / 季节、饱和度 / 质感、单色 / 双色 / 渐变、风格化命名
- 三、主色(29 种):蓝、绿、紫、红粉、橙黄金、中性棕褐
- 四、成套协调系统(12 套整机配方):底×墨×线×accent组×字体分工×母题×图表风一次对齐；命中 register 时借关系,按 case 转译

## 四、成套协调系统(resolved systems:三维一次锁定的整机配方)

> 前三节是**零件**(风格 / 色调 / 主色);这一节是**装好的整机参考**——每套都把〔底 × 墨 × 线 × accent 组 × 字体分工 × 招牌母题 × 图表风〕全部调到互相咬合。**整册协调(deck-level coherence)来自对一套关系系统的承诺,不是每页各自好看的拼装。** brief 命中某 register 时,优先借用这套关系系统,但必须经 `plan/design-brief.md` 转译:说明本 case 保留哪些层、删掉哪些不合适的招牌动作、怎样改成材料 / 受众 / 场合自己的语言。宁可一套逻辑贯彻到底,也别五页五个调子。
>
> **怎么借一套**:①〔底/墨/线〕落到 `--bg`/`--ink`/`--ink-dim`/`--line`/`--panel`；②〔accent 组〕定义清楚主次角色，多色只在分类、色带或分区确有意义时出现，不每页乱撒；③〔字体分工〕按本地 token 落地并由场合正式度复核；④〔母题〕翻译成服务本 case 的封面、章节或 hero 语法，在足以建立亲缘性的关键页回应，不按次数贴图。hex 是起点、可按主题微调，但一套之内不随意换调子。⭐ = 纯 CSS 可复刻；⚠ = 招牌母题依赖图片素材，无素材时按注解退化。
>
> **与 anti-slop 对齐(要紧)**:这些系统是**命中 register 才搬的有意选择**,**不豁免**「别反射式默认」——题材没明确要炫时,回**克制编辑基准**(S1 那类纸感克制),别顺手抓 S8/S4 的霓虹辉光、S12 的黑金渐变当默认;发光 / 渐变 / 金属质感 / 玻璃辉光球只在**题材真需要**时用,且对比度 gate 照过、径向光晕别当假景深。
